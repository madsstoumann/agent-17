Six files to start, more by trigger

A project scaffolded by /project:new starts with six files people write and three the system keeps. Phases set the focus and the client output; they do not lock files. Colours follow the planning board, and purple files live across every phase. A change is written once, as a change record; versions, changelogs and the decision list are built from it.

  • Living file, every phase
  • File owned by one phase
  • Optional, added on a trigger
  • Generated or kept by the system, from the change records
  • Skill
  • Session or meeting
  • Input: recordings, notes
